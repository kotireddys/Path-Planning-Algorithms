Path-Planning-Algorithms
========================

Phase 1: 2D Path Planning Sandbox (A*, RRT, RRT*, Dubins)

This repository contains educational implementations of classic 2D path planning
algorithms and simple visualization utilities.

Quick start

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run a demo (A* or RRT):

```bash
python examples/run_demo.py --algo astar
python examples/run_demo.py --algo rrt
```

The script will generate an animated GIF in the repo folder.
